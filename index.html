How the pipeline works

STAGE 1

Ingest & type repair

Reads Excel, CSV or pasted text. Numbers that Excel mangled into scientific notation (9.19876E+11) are expanded back to full digits before anything else touches them.

STAGE 2

Email cleaning

Trims whitespace, strips inner spaces and trailing punctuation, lowercases, then validates against a strict pattern. Optionally repairs frequent domain typos — every repair is marked, never silent.

STAGE 3

Phone normalization

Strips spaces, dashes, dots and brackets; converts the international 00-prefix to +; drops a single trunk-zero where a country expects it. Only digits survive.

STAGE 4

Country-code routing

Longest-prefix match against the full ITU dial-code table (240+ codes, tried 3→2→1 digits), cross-checked against each country's expected national number length. No prefix present? The default country applies only when the length fits exactly — otherwise the row is flagged, never guessed.

STAGE 5

Deliver

Optional de-duplication, then export. In the Excel download the code and number columns are written as text so Excel can never re-mangle them.

Everything runs in your browser — no row of your data leaves this page.
